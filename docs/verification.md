## 仕様上の前提(2026-11-05 に確認済み)

- `kintone.plugin.app.setProxyConfig` を同じ URL で GET と POST の2回呼んでも、両方が保持される(#6 の POST と #11 / #12 の GET が同じ保存で通った)
- `kintone.plugin.app.proxy` の GET で `data` に空文字を渡しても問題ない(#11 / #12)

## 確認で見つけて直したこと

- 設定画面のトークン欄(ネイティブの `input`)のラベルが、kintone UI Component の他の欄と見た目が揃っていなかった → CSS を追加
- プラグインのアイコンが仮の 1bit 画像で空白に見えていた → 56px のアイコンを作成

## 環境のメモ

- 確認は REST API を使って行った(アプリ作成・フィールド追加・レコード作成・フィールドのアクセス権の変更)。画面操作は設定画面とボタン押下のみ
- #7 はタイトルの必須設定を一時的に外して空のレコードを作り、確認後に戻した
- #13 は `issue_number` のフィールドアクセス権を Everyone 閲覧のみにして作成し、権限を戻してから再試行した
